# Stage B error attribution and controlled alternatives

Formal benchmark predictions and metrics remain the primary evidence. The
supplemental ED/LP audit contributes only hard-logic and cost-component fields,
joined by the four formal key fields and never by row order. The two source
directories are immutable.

Primary summaries retain every formal row. Sensitivity summaries separately
show hard-logic feasibility, zero/nonzero balance penalty, and penalty-dominant
rows, fixed before comparison as `(balance_penalty + reserve_penalty) / true_cost >= 0.5`.
Reserve penalties have no nonzero samples and are reported as N/A.

Controlled alternatives use the identical 27 unit/split protocol and fit-only
labels: quadratic-Ridge residual models, the frozen simplified-QNN residual
model, and fixed margin/ranking objectives. Model seeds are aggregated inside
each unit before paired statistics and bootstrap intervals over 27 units.
